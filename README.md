# Saleem El Bouri

AI Engineer in Amman, Jordan. I build document intelligence systems: pipelines that take unstructured documents and make their contents retrievable, answerable, and traceable back to the source page. I work in Arabic and English.

## What I focus on

- **Retrieval-augmented generation (RAG):** parsing, chunking, hybrid retrieval, re-ranking, grounded generation
- **Retrieval evaluation:** golden sets, MRR, Recall, LLM-as-a-judge
- **Arabic NLP:** classification and text understanding with AraBERT-style models
- **Data work:** ETL pipelines, document data extraction, dashboards
